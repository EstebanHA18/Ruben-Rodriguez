# Rubén Rodríguez — Plataforma Web Oficial

Sitio web y plataforma de marca personal para el creador de contenido y comunicador **Rubén Rodríguez** ([@rubenrodriguezofficial](https://www.tiktok.com/@rubenrodriguezofficial)).

## 🌟 Pilares de Contenido
- **Comunicación Efectiva:** Storytelling, oratoria y conexión genuina.
- **Comedia & Entretenimiento:** Humor inteligente y situaciones cotidianas.
- **Bienestar & Rescate Animal:** Visibilización, campañas de adopción y defensa animal.
- **Casos Sociales & Comunidad:** Apoyo comunitario y solidaridad activa.

## 🚀 Tecnologías & Arquitectura
- **Diseño:** Minimalista Ultra Moderno (Dark Mode Obsidian con acentos Mostaza Oro).
- **Core:** HTML5 Semántico, CSS3 Modular (Glassmorphism & Micro-interacciones), JavaScript Vanilla moderno.
- **Tooling:** Vite v8 para compilación de alto rendimiento.
- **SEO & Performance:** Datos estructurados Schema.org JSON-LD (`Person` & `ProfilePage`), OpenGraph, Twitter Cards, `sitemap.xml` y `robots.txt`.

## 🛠️ Instalación y Uso Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar versión de producción
npm run build
```
